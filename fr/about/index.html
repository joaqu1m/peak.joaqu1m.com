À propos

PEAK Daily Map est un projet réalisé par un fan, qui lit les données directement dans les fichiers du jeu PEAK : la carte du jour et des prochains jours, la position exacte des objets et des valises, les chances de loot et les 64 succès — en 15 langues.

D’où viennent les données

Rien ici n’est deviné. La rotation des cartes, la position des objets et les tables de loot sont lues directement dans le code du jeu. Les descriptions de chaque objet sont écrites à la main, en comparant le comportement en jeu avec le wiki officiel.

Avertissement

Il s’agit d’un projet non officiel, réalisé par un fan. PEAK est un jeu d’Aggro Crab et Landfall — ce site n’a aucune affiliation avec eux.
