Política de privacidad

PEAK Daily Map es un sitio estático hecho por un fan. No tiene servidor propio, ni cuentas, ni base de datos: cada página es un archivo que se entrega tal cual.

Qué se guarda en tu navegador

En el almacenamiento local de tu navegador se guardan dos preferencias: el idioma que elegiste y si cambiaste al tema oscuro. Permanecen en tu dispositivo, nunca se envían a ninguna parte y no podemos leerlas. Al borrar los datos del navegador se eliminan.

Qué registra el alojamiento

El sitio se sirve desde GitHub Pages a través de Cloudflare. Como cualquier servidor web, registran datos técnicos de la solicitud —dirección IP, identificación del navegador y la página solicitada— para entregar el tráfico y protegerse frente a abusos. Esos datos los manejan GitHub y Cloudflare bajo sus propias políticas de privacidad, no este sitio.

Publicidad

Este sitio puede mostrar anuncios de Google AdSense. Google y sus socios usan cookies para mostrar anuncios según tus visitas anteriores a este y a otros sitios web. Puedes desactivar la publicidad personalizada en la configuración de anuncios de Google.

Tus opciones

Puedes borrar las preferencias guardadas cuando quieras desde la configuración de tu navegador, y puedes bloquear cookies o usar un bloqueador de contenido. Nada en este sitio exige que te identifiques.

Las dudas sobre esta política pueden plantearse como un issue en el repositorio del sitio en GitHub.
