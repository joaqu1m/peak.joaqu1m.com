Politique de confidentialité

PEAK Daily Map est un site statique réalisé par un fan. Il n’a ni serveur propre, ni compte, ni base de données : chaque page est un simple fichier, servi tel quel.

Ce qui est enregistré dans ton navigateur

Deux préférences sont conservées dans le stockage local de ton navigateur : la langue que tu as choisie et le fait que tu sois passé au thème sombre. Elles restent sur ton appareil, ne sont jamais transmises et nous ne pouvons pas les lire. Effacer les données du navigateur les supprime.

Ce que l’hébergeur journalise

Le site est servi par GitHub Pages via Cloudflare. Comme tout serveur web, ils journalisent des données techniques de requête — adresse IP, identification du navigateur et page demandée — pour acheminer le trafic et se protéger des abus. Ces données sont traitées par GitHub et Cloudflare selon leurs propres politiques de confidentialité, pas par ce site.

Publicité

Ce site peut afficher des annonces diffusées par Google AdSense. Google et ses partenaires utilisent des cookies pour proposer des annonces en fonction de tes visites précédentes sur ce site et sur d’autres. Tu peux désactiver la publicité personnalisée dans les paramètres des annonces Google.

Tes choix

Tu peux effacer les préférences enregistrées à tout moment depuis les réglages de ton navigateur, bloquer les cookies ou utiliser un bloqueur de contenu. Rien sur ce site ne t’oblige à t’identifier.

Les questions sur cette politique peuvent être posées sous forme d’issue dans le dépôt GitHub du site.
