사이트 소개

PEAK Daily Map은 PEAK 게임 파일에서 데이터를 직접 읽어오는 팬 제작 프로젝트예요. 오늘과 앞으로 며칠간의 맵, 아이템과 짐의 정확한 위치, 루팅 확률, 64개 업적을 15개 언어로 제공해요.

데이터는 어디서 오나요

여기 있는 내용은 추측이 아니에요. 맵 로테이션, 아이템 위치, 루팅 테이블은 모두 게임 코드에서 직접 읽어와요. 각 아이템 설명은 게임 내 실제 동작을 공식 위키와 대조하며 직접 작성했어요.

안내

이 사이트는 팬이 만든 비공식 프로젝트예요. PEAK는 Aggro Crab과 Landfall이 만든 게임이며, 이 사이트는 그들과 아무런 관련이 없어요.
