개인정보 처리방침

PEAK Daily Map은 팬이 만든 정적 사이트예요. 자체 서버도, 계정도, 데이터베이스도 없어요. 모든 페이지는 파일 그대로 전달돼요.

브라우저에 저장되는 것

브라우저의 로컬 저장소에는 두 가지 설정만 저장돼요. 선택한 언어와 어두운 테마로 바꿨는지 여부예요. 이 정보는 기기 안에 남고, 어디로도 전송되지 않으며, 저희가 읽을 수도 없어요. 브라우저 데이터를 지우면 함께 삭제돼요.

호스팅이 기록하는 것

이 사이트는 Cloudflare를 통해 GitHub Pages에서 제공돼요. 다른 웹 서버와 마찬가지로 요청의 기술 정보 — IP 주소, 브라우저 식별 정보, 요청한 페이지 — 를 트래픽 전달과 악용 방지를 위해 기록해요. 이 데이터는 이 사이트가 아니라 GitHub와 Cloudflare가 각자의 개인정보 처리방침에 따라 다뤄요.

광고

이 사이트에는 Google AdSense가 제공하는 광고가 표시될 수 있어요. Google과 파트너사는 이 사이트와 다른 사이트를 방문한 기록을 바탕으로 광고를 노출하기 위해 쿠키를 사용해요. 맞춤 광고는 Google 광고 설정에서 끌 수 있어요.

선택할 수 있는 것

저장된 설정은 언제든 브라우저 설정에서 지울 수 있고, 쿠키를 차단하거나 콘텐츠 차단기를 쓸 수도 있어요. 이 사이트에서 신원을 밝혀야 하는 일은 없어요.

이 방침에 대한 문의는 사이트의 GitHub 저장소에 issue로 남겨 주세요.
