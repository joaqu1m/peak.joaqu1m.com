隱私權政策

PEAK Daily Map 是一個由粉絲製作的靜態網站。它沒有自己的伺服器、帳號或資料庫：每個頁面都是一個檔案，原樣提供。

瀏覽器中儲存的內容

瀏覽器的本機儲存空間中只保存兩項偏好：你選擇的語言，以及是否切換到深色主題。它們留在你的裝置上，絕不會傳送到任何地方，我們也無法讀取。清除瀏覽器資料即可刪除。

主機記錄的內容

本站透過 Cloudflare 由 GitHub Pages 提供服務。與任何網頁伺服器一樣，它們會記錄請求的技術資料——IP 位址、瀏覽器識別和所請求的頁面——用於傳送流量並防範濫用。這些資料由 GitHub 與 Cloudflare 依各自的隱私權政策處理，而非本站。

廣告

本站可能顯示由 Google AdSense 提供的廣告。Google 及其合作夥伴會使用 Cookie，依你先前造訪本站與其他網站的紀錄來投放廣告。你可以在 Google 廣告設定中關閉個人化廣告。

你的選擇

你可以隨時在瀏覽器設定中清除已儲存的偏好，也可以封鎖 Cookie 或使用內容封鎖器。本站的任何內容都不要求你表明身分。

關於本政策的疑問，可在本站的 GitHub 儲存庫中以 issue 形式提出。
