隐私政策

PEAK Daily Map 是一个由粉丝制作的静态网站。它没有自己的服务器、账号或数据库：每个页面都是一个文件，原样提供。

浏览器中保存的内容

浏览器的本地存储中只保存两项偏好：你选择的语言，以及是否切换到了深色主题。它们留在你的设备上，绝不会发送到任何地方，我们也无法读取。清除浏览器数据即可删除。

主机记录的内容

本站通过 Cloudflare 由 GitHub Pages 提供服务。与任何网页服务器一样，它们会记录请求的技术数据——IP 地址、浏览器标识和所请求的页面——用于传送流量并防范滥用。这些数据由 GitHub 和 Cloudflare 依据各自的隐私政策处理，而非本站。

广告

本站可能展示由 Google AdSense 提供的广告。Google 及其合作伙伴会使用 Cookie，根据你此前对本站及其他网站的访问来投放广告。你可以在 Google 广告设置中关闭个性化广告。

你的选择

你可以随时在浏览器设置中清除已保存的偏好，也可以屏蔽 Cookie 或使用内容拦截器。本站的任何内容都不要求你表明身份。

关于本政策的疑问，可在本站的 GitHub 仓库中以 issue 形式提出。
