Warp Compass · 5.0 kg

What it does

Warp compass (3 uses): takes you to a random faraway player (at least 12 m away). If no one is far enough, the use is refunded.

Effects

  • Teleports you to a random distant player
  • Use refunded if there is no valid target

Variations

  • Warp compass (1 use, shortcut item): warps the group straight to the Caldera.
  • Warp compass (1 use, shortcut item): warps the group straight to The Kiln.
