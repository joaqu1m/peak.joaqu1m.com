Флаг контрольной точки

Checkpoint Flag · 5.0 кг

Что делает

Флаг контрольной точки: установите его, чтобы создать одноразовую точку возрождения только для себя — больше никто там не возрождается. Он сохраняет ваши статусы на момент установки и восстанавливает их при возрождении.

Эффекты

  • Создаёт одноразовую точку возрождения
  • Действует только для того, кто установил флаг, а не для всей группы
  • Сохраняет ваши статусы на момент установки и восстанавливает их при возрождении
  • Можно приготовить только с помощью взрывчатки
