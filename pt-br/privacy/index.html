Política de privacidade

O PEAK Daily Map é um site estático feito por fã. Ele não tem servidor próprio, não tem conta e não tem banco de dados — cada página é um arquivo, entregue como está.

O que fica guardado no seu navegador

Duas preferências ficam no armazenamento local do seu navegador: o idioma que você escolheu e se você trocou para o tema escuro. Elas permanecem no seu aparelho, nunca são enviadas para lugar nenhum e não podem ser lidas por nós. Limpar os dados do navegador apaga as duas.

O que a hospedagem registra

O site é servido pelo GitHub Pages através da Cloudflare. Como qualquer servidor web, eles registram dados técnicos da requisição — endereço IP, identificação do navegador e a página pedida — para entregar o tráfego e se proteger contra abuso. Esses dados são tratados pelo GitHub e pela Cloudflare sob as políticas de privacidade deles, não por este site.

Anúncios

Este site pode exibir anúncios do Google AdSense. O Google e seus parceiros usam cookies para exibir anúncios com base nas suas visitas anteriores a este e a outros sites. Você pode desativar os anúncios personalizados nas Configurações de anúncios do Google.

Suas escolhas

Você pode apagar as preferências guardadas a qualquer momento nas configurações do navegador, e pode bloquear cookies ou usar um bloqueador de conteúdo. Nada neste site exige que você se identifique.

Dúvidas sobre esta política podem ser abertas como issue no repositório do site no GitHub.
